# terraform-vault-platform

Portfolio project: HA HashiCorp Vault cluster on AWS EC2 with Raft
integrated storage, KMS auto-unseal, PKI subordinate CA, and dynamic
Postgres credentials via RDS.

Same apply/demo/destroy-same-day pattern as
[terraform-eks-platform](https://github.com/bibigon14/terraform-eks-platform).

See [docs/bootstrap.md](docs/bootstrap.md) for one-time setup.
